# Software Engineering Scenario

The default GSD scenario for software project development.

## What it provides

**Workflow:** questioning → research → roadmap → execute → verify

**Commands:** `/gsd:new-project`, `/gsd:plan-phase`, `/gsd:execute-phase`, `/gsd:verify-phase`, and 30+ more

**Agents:** 15 specialized agents (planner, executor, verifier, researcher, debugger, etc.)

**Use for:** Building software projects with structured phase planning, automated verification, and git integration.

## Directory structure

- `workflows/` — 30+ workflow orchestration files
- `agents/` — Placeholder for agent-specific workflows
- `templates/` — Document generation templates (PROJECT.md, ROADMAP.md, PLAN.md, etc.)
- `references/` — Shared knowledge documents (questioning, git integration, TDD, etc.)
